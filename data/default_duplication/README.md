# Default-duplication measurements

These unchanged derived records support distribution-level analysis of repeated
default entries. `historical_mixture.json` contains 168 retrospective dose contrasts.
`local_cases.json` defines the local menus and tasks; `local_raw.json` retains
84 constrained-choice distributions, allowed-token probabilities, model revisions
and prompt hashes. `local_results.json` contains their analysis, including failed
criteria. `math_validation.json` records algebraic checks.

The local challenge used two Qwen scales on three AutoML datasets, not new protein
experiments or independent model families. Both models failed both frozen criteria.
A mass-matched diagnostic conditions on observed post-intervention default mass;
it is not a pre-intervention predictor. Historical hosted logits are probability
proxies and retain their sampling-validity limitation.

These records are provided for evidence inspection. The repository's four replay
commands do not constitute a complete replay of this additional analysis. No
outcomes were regenerated or selected during release packaging.
